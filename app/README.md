# app/ — Bizzing Maths

Vanilla ES modules + Vite, `state → render()` returning a string, clicks dispatched by
`[data-act]` — the Bizzing Bee idiom, on Bizzing Finance's architecture.

```bash
npm install
npm run dev        # Vite on :5173
npm test           # tricks (3 routes × ~57k questions), facts, contest, puzzles, model
npm run build      # -> build/, relative base, drops onto any static host
npm run check      # drives build/ under /Bizzing-Maths/ in Chromium, desktop + phone
./deploy.sh        # test + build + publish gh-pages
```

## Module map

| file | what it owns |
|---|---|
| `src/tricks.js` | `WORLDS` (5) and `TRICKS` (27). Each chapter: `hook`, `idea`, `work(q)` steps, `why`, `alg`, `gen(r, lv)`, `q()`, optional `sutra`, `fig`. `drill()`, `correct()`. |
| `src/facts.js` | `BANK` (434 facts), `tricky()`, `why()`, `ramp()`, Leitner `record()`/`state()`, `session()` (discovery for a new child, then traps → due → ≤4 new → known). |
| `src/model.js` | Household/kid shape, `RANKS`, `ROUTE`, `frontier()` (skips nodes optional for the child's band or placement), `isOpen()`, `scoreRun()` stars, `RUNGS` + `placeFrom()`. |
| `src/contest.js` | `RIVALS` (the Bee's ten), the hardness ladder, `playRound()`, `championship()`, `runOut()`. |
| `src/games.js` | Overlay frame, shared `keypad()`, `numberRush`, `makeTarget` (+ `solve`, `makePuzzle`), `numberLine`. |
| `src/figs.js` | SVG figures: `jumps`, `area`, `grid`. |
| `src/views.js` | Every screen. |
| `src/main.js` | Boot, hash routing, the question runner, guided steps, contest driver, keys, all actions. |
| `src/store.js` | The seam: household + device buckets, versioned `migrate()`, backup/restore. |
| `src/ui.js` | From Finance: `esc`, dispatch, WebAudio `sfx`, `toast`, `confetti`; `say`/`hush` re-exported from voice.js. |
| `src/voice.js` | Read-aloud: plays the family narrator's clips (a fixed line whole, a generated question as a chain of pieces), lazily, one utterance at a time; any missing piece → the whole line goes to the device voice. Silent when muted. |
| `src/voice-text.js` | The one tokeniser: text → recorded pieces (numbers 0–100 compose everything up to 999,999,999; fractions, times, units, Roman letters). `keyOf()` names a clip. |
| `src/voice-manifest.js` | GENERATED by `tools/voice/tts.py`: key → `{ f, d }` for clips on disk that passed the lint. |
| `src/lines.js` | The fixed sentences a child hears (Nova's onboarding lines, the wrong-answer reply). |
| `sw.js` | From Finance: hashed assets cache-first, the rest network-first; `voice/` clips cached on use in their own cache, never precached. |
| `public/avatars/` | 21 of Bizzing Bee's painted avatars (192px): the child's picker, Aryabhata, and the ten rivals. |
| `public/voice/` | The narrator's clips (en-IN-Chirp3-HD-Laomedeia, rate 1.02, 32 kb/s mono). |

## Narration

Read-aloud is on by itself for a 6–7 child (`model.js readOn`: a grown-up's choice wins; until
one is made it follows the band), and a 🔊 on every question (or `R`) for everyone. The clip list
is asked of the app, never kept: `tools/voice/clips.mjs` samples every stop on journey levels 1–3
at drill levels 1–3 plus the whole facts bank, and adds the fixed lines (guide, hooks, stories,
test gates). To (re)record what is new:

```bash
GKEY=$(cat /root/.gkey2) python3 tools/voice/tts.py --prune   # 4 workers; rejects < −20 dB mean or < 0.35 s; flags stale clips by mtime
npm run voice:lint                                              # measures every clip (needs ffmpeg)
```

`test/voice.mjs` (in `npm test`) fails when a young question would fall back to the device
voice, when a clip outlives its sentence, or when a file fails the lint — and proves its
coverage check by breaking it (no "seven") every run.
